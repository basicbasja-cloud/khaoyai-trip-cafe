# เขาใหญ่ Cafe Guide ☕ — 5 ตัวเลือกคาเฟ่ เลือกที่ใช่แล้วไป

เว็บไกด์คาเฟ่เขาใหญ่แบบเปิดบนมือถือได้เลย — 5 ร้านคือ **ตัวเลือก** (ไม่ต้องไปครบทุกที่)

## เปิดดู
- เปิด `index.html` (หรือ `khaoyai-cafe-trip.html`) ในเบราว์เซอร์ได้ทันที
- ถ้าเปิด GitHub Pages: https://basicbasja-cloud.github.io/khaoyai-trip-cafe/

## มีอะไรบ้าง
- 🗺️ แผนที่ภาพรวม (Leaflet + OpenStreetMap) ปักหมุดที่พัก 🏠 + คาเฟ่ 5 ร้าน พร้อมเส้นระยะ
- 📍 ปุ่ม "ตำแหน่งฉัน (GPS)" หาตำแหน่งปัจจุบัน + บอกร้านใกล้สุดแบบเรียลไทม์
- 🤔 ตัวช่วยเลือกตาม vibe (ใกล้ที่พัก / สายถ่ายรูป / นั่งชิล / ครอบครัว / เช้าแสงสวย)
- ⚖️ ตารางเทียบ 5 ร้าน — สไตล์ / ระยะ / เหมาะกับใคร
- 🧭 Google Maps นำทางจริงฝังในเว็บ (จิ้มปุ่ม 1–5 วางเส้นทางขับรถจากที่พัก) + ปุ่มเปิดในแอปนำทาง
